# flim-coherent-cube-gui

Control a [Coherent Cube laser](https://www.coherent.com/resources/manuals/lasers/CUBE_Laser_Operators_Manual_1079231_RevAH_screen.pdf) attached to a [pco flim.X camera](https://www.excelitas.com/product/pcoflim-x). 
Intended for use in the FLIM setup at the [ipv, University of Stuttgart](https://www.ipv.uni-stuttgart.de/).

## Installation

```console
pip install flim-coherent-cube-gui
```
